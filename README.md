# hyper-casual-games

Tiny hyper-casual games from the *Crushing Hyper Casual* playbook (Trey Smith).
Built by Hans + Bug. Web-first, one-touch, portrait.

## The playbook (distilled)
- **Model and improve** — take a proven mechanic, add one twist. Never a clone.
- **One touch or swipe. Portrait only.** Never landscape, never buttons.
- **10/10 design** or don't ship. Small objects, consistent universe, clutter-free UI.
- **Difficulty ramps subtly**; death must feel 100% the player's fault; let levels breathe.
- **Retention**: wonder (what's next?), surprise, perfect-level annoyance, competitiveness (high score).
- Build fast, ship many, keep winners.
