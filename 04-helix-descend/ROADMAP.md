# Helix Descend — Roadmap

Improvement ideas are tracked in [issue #5](https://github.com/builtbysai/hyper-casual-games/issues/5):

1. **Goals** — daily goal (30 rings/day) + 3 random per-run goals, checkmark celebration.
2. **Time Attack** — 60-second mode beside Endless, mode select on start screen.
3. **Unlockable themes** — Dusk (level 3), Neon (level 5), Desert (level 8); change bg, tower, platforms, ball trail.
4. **More challenge** — rotation speed + gap frequency ramp with depth, moving platforms later, gravity scales up. Core bounce/rotate feel untouched.
5. **Combo** — consecutive perfect landings build a score multiplier (up to x3).

A previous implementation of these was built and pushed, but the execution was poor, so it was reverted. Do not re-implement from the reverted commit — design each one properly first.
